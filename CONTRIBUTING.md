# Contributing

Thanks for helping improve this repository.

## Contribution Rules

- Keep scripts focused on one problem.
- Add a short description at the top of each script:
  - What issue it addresses
  - Supported environment(s)
  - Any prerequisites
  - How to run it safely
- Include rollback or recovery notes when applicable.
- Do not include secrets, passwords, tokens, or private paths.

## Script Naming

Use descriptive names, for example:

- `fix-network-dns.ps1`
- `reset-print-spooler.bat`
- `repair-python-path.py`

## Pull Requests

- Explain the issue and the fix clearly.
- Include test or validation steps.
- Keep changes small and easy to review.
